# Dash Dodge

Mobile-first endless three-lane dodge runner built with TypeScript, Phaser 3 and Vite.

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

The game is designed to be fully offline in its shipped app. Android packaging is planned with Capacitor during Day 7.

See `PROJECT_STATE.md` for the one-week build plan and current status.
