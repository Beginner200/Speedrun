# Store asset specification

## Required artwork

- App icon: 512 x 512 PNG source for store use, with a simple high-contrast Dash Dodge mark.
- Feature graphic: 1024 x 500 PNG/JPG for the store listing.
- Phone screenshots: portrait screenshots showing Home, active gameplay, power-ups/game-over, Shop, and Daily Reward/Missions.
- Keep important text and logos away from device cutout/status-bar areas.

## Visual direction

Use the game's existing bright high-contrast visual language: dark blue background, mint player, warm obstacle/coin accents, clean vector shapes, and readable typography.

## Screenshot plan

1. Home screen — title, Play, coins and best score.
2. Gameplay — three-lane road, player, obstacles and HUD.
3. Power-ups — Shield/Magnet and coin collection.
4. Progression — Shop and cosmetic skins.
5. Rewards — Daily Reward/Missions/local leaderboard.

## Native Android note

The Android launcher icon and splash screen must ultimately be installed as Android resources. SVG source artwork can be used as a design source, but final Android/store PNG and density-specific resources must be generated and verified in the native project.

## Final checks

- [ ] No copyrighted/unlicensed third-party artwork.
- [ ] No misleading gameplay screenshots.
- [ ] Screenshots represent the shipped version.
- [ ] Feature graphic uses the final app name.
- [ ] Icon remains legible at small sizes.
