# Dash Dodge Privacy Notice

**Last updated:** 2026-10-06

Dash Dodge is designed as an offline game.

## Data stored

The game stores gameplay progress locally on your device, including coins, best scores, owned/equipped skins, daily-reward state, mission progress, settings, and your personal local leaderboard.

## Network and accounts

Dash Dodge does not require an account and does not send gameplay data to a game server. The game does not include online leaderboards, advertising SDKs, analytics SDKs, or payment processing in this version.

## Device permissions

The game may use vibration/haptics when enabled in Settings. It does not require contacts, location, camera, microphone, or photo-library access.

## Third-party services

The web build uses Phaser and standard browser APIs. The Android wrapper uses Capacitor. No third-party analytics or advertising service is included in the current release build.

## Deleting local data

Use **Settings → Reset Progress** inside the game to remove locally stored Dash Dodge progress.

## Changes

This notice may be updated when the game's data practices change. Any future online services, advertising, analytics, accounts, or payments will require an updated privacy notice and release review.
